# Medical-Data-Visualizer 
Medical Data Visualizer

A Python project from the freeCodeCamp Data Analysis with Python course.

This project uses Pandas, Matplotlib, Seaborn, and NumPy to analyze medical examination data.

Features
Creates a categorical plot showing health factors by cardiovascular disease.
Creates a correlation heat map.
Cleans and processes the medical data.
Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
Run
python main.py
